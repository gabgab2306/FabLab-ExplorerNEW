# Backend adapters (preparado, no conectado)

Los adaptadores de proveedores se mantienen en el servidor. No se realiza scraping ni se aceptan URLs arbitrarias aportadas por el usuario. Las integraciones comerciales deben implementarse con las APIs autorizadas disponibles para la cuenta y región del proyecto, validando respuestas y limitando solicitudes. Mientras no estén configuradas, se conserva el catálogo local y los precios de ejemplo siguen marcados como estimaciones.
